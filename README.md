# NICE FAITH LAB

P4 마스터 명세에 따른 SolidJS + TypeScript + Vite 모바일 우선 MVP입니다. 금융 신용평가 경험을 패러디한 기독교 교육·성찰 앱이며 실제 NICE 신용평가사와 무관합니다.

## 실행 및 검증

Node.js 22.12 이상을 사용하세요. Node.js 24.14.1에서 검증했습니다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

개발 서버의 기본 주소는 `http://127.0.0.1:5173/`입니다. 빌드 결과는 `dist/`에 생성됩니다.

## 사용자 흐름

시작 → 12문항 설문 → 분석 → 상세 리포트 → 점수 소멸 애니메이션 → 개인화 성찰·공유.

- 모든 질문은 선택 또는 건너뛰기가 가능하며, 이전 문항과 브라우저 뒤로/앞으로 이동 시 응답을 보존합니다.
- 질문의 선택지는 기본 라디오 버튼으로 키보드 Tab·방향키·Space를 지원합니다.
- 미응답·평가 제외 응답은 중립값 50을 사용합니다. 채점 가능한 응답이 없으면 계산을 거부합니다.
- Q1–Q10만 5개 영역에 동일 비중으로 반영합니다. Q11·Q12는 성찰 문구에만 사용합니다.
- 총점은 `1 + Math.round(999 * sum(domainScores) / 500)`입니다. 영역의 중간 점수는 반올림하지 않습니다.
- 점수 범위는 1–1,000이며, 실제 질문의 최저 선택 조합은 131점입니다. 이는 일부 질문의 최저값이 0이 아니기 때문입니다.
- 반전은 점수 값을 바꾸지 않고 소멸시킵니다. `src/screens/RevealScreen.tsx`의 `revealTiming`에서 시점을 조정합니다.
- 분석과 반전은 건너뛰기·동작 줄이기를 지원하고 화면 이탈 시 타이머를 해제합니다.
- 최종 성찰 화면에는 점수·등급·그래프가 없습니다. 브라우저 뒤로 이동하면 기존 리포트 및 답변을 다시 검토할 수 있습니다.
- `#/reflection` 직접 진입은 일반 성찰 문구를 표시합니다. 응답 없이 `#/report`·`#/evaluation`·`#/reveal`에 접근하면 첫 질문으로 안내합니다.
- 다시 시작하면 메모리의 모든 답변을 초기화합니다. 새로고침 시에도 응답은 사라집니다.

## 데이터와 공유

백엔드·로그인·분석 도구·쿠키·localStorage·sessionStorage를 사용하지 않습니다. 질문 응답과 리포트는 메모리에만 존재하며, 브라우저 기록에는 화면 경로만 저장합니다. 웹 폰트나 외부 자산을 요청하지 않으며 시스템 글꼴을 사용합니다. 호스팅 서비스의 일반 접속 로그에는 답변이 포함되지 않습니다.

공유 함수는 답변이나 리포트를 인자로 받지 않습니다. Web Share API와 주소 복사를 지원하며 쿼리와 해시를 제거한 앱 주소만 공유합니다. 클립보드 권한이 없으면 직접 복사할 주소를 표시합니다. PNG는 Canvas로 브라우저에서 생성하며 모든 사용자에게 동일한 고정 문구만 담습니다. 개인화 성찰·점수·등급·답변은 공유하지 않습니다.

## 파일 소유권

- `src/data/questions.ts`: 질문·선택지·점수의 유일한 정의
- `src/domain/scoring.ts`: 순수 점수·등급·기여도 산출
- `src/data/reflectionCopy.ts`: Q11·Q12 개인화 문구
- `src/domain/sharing.ts`: 개인 데이터 없는 URL·PNG 생성
- `src/app/`: 메모리 응답 상태와 해시 기반 브라우저 탐색
- `src/screens/`: 6개 화면
- `src/tests/`: 채점 경계·결정성·성찰·공유·사용자 흐름·타이머 검증

## Cloudflare Pages

프레임워크: Vite. 빌드 명령: `npm run build`. 출력 폴더: `dist`. 환경변수나 서버는 필요하지 않습니다. Node.js 24를 지정하세요. 해시 경로를 사용하므로 별도의 서버 라우팅 규칙 없이 직접 진입이 가능합니다. 이 작업에서는 외부 배포를 수행하지 않았습니다.

## 명세상 남은 확인 사항

P4는 개역개정 발췌문을 **번역 표기와 사용 조건을 확인한 후** 사용하도록 요구합니다. 이번 작업에서는 대한성서공회의 사용 조건을 공식 자료로 확인하지 못했습니다. 따라서 해당 문구를 성경 인용으로 표시하지 않고, 에베소서 2:8–10의 뜻을 풀어 쓴 자체 설명과 [대한성서공회 본문 링크](https://www.bskorea.or.kr/bible/korbibReadpage.php?version=GAE&book=eph&chap=2)를 제공합니다. 승인된 인용문을 적용하려면 사용 조건을 먼저 확인해야 합니다.

데스크톱 브라우저에서 모바일 너비를 검수했으며 실제 iOS·Android 기기와 운영체제별 공유 화면은 검증 범위 밖입니다.
