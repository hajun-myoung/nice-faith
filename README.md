# NICE FAITH

**당신의 믿음, 몇 점입니까?**

![NICE FAITH — 당신의 믿음, 몇 점입니까?](public/og-default.png)

NICE FAITH는 12개의 질문으로 평소의 신앙생활을 돌아보는 웹 앱입니다. 익숙한 금융 신용평가 화면을 빌려 예배, 기도, 말씀, 공동체, 일상 속 활동을 살펴보고, 숫자가 담을 수 있는 것과 담을 수 없는 것을 생각합니다.

기독교 신앙을 주제로 한 독립 교육용 패러디이며, 실제 NICE 신용평가사와 관련이 없습니다. 점수와 등급은 가상의 활동지표로, 실제 신앙이나 구원의 상태를 판단하지 않습니다.

## 주요 기능

- **12문항 설문** — 답변을 고르면 다음 질문으로 이동하며, 이전 문항으로 돌아가 수정할 수 있습니다.
- **신앙활동 리포트** — 5개 영역의 활동지표와 점수에 영향을 준 항목을 확인합니다.
- **개인화 성찰** — 마지막 두 질문의 답변에 맞춰 돌아볼 이야기를 건넵니다.
- **결과 공유** — 점수와 선택한 별명을 링크로 공유합니다. 링크를 받은 사람은 공유 결과를 보고 자신의 설문을 시작할 수 있습니다.
- **모바일과 접근성** — 모바일 화면, 키보드 조작, 화면 읽기 프로그램, 동작 줄이기 설정을 지원합니다.

## 기술 구성

SolidJS · TypeScript · Vite · Tailwind CSS · Lucide · Vitest

설문과 채점은 브라우저에서 실행합니다. Vercel Function은 공유 링크의 이름과 점수를 Open Graph 메타데이터에 반영합니다. 데이터베이스나 회원가입은 사용하지 않습니다.

## 로컬 실행

Node.js 24를 권장합니다. 저장소를 내려받은 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

| 명령                | 용도                 |
| ------------------- | -------------------- |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm test`          | 테스트 실행          |
| `npm run build`     | 프로덕션 빌드        |
| `npm run preview`   | 빌드 결과 미리보기   |

## 배포

Vercel에서 Git 저장소를 연결하면 포함된 `vercel.json` 설정으로 배포할 수 있습니다.

| 설정             | 값              |
| ---------------- | --------------- |
| Framework Preset | Vite            |
| Build Command    | `npm run build` |
| Output Directory | `dist`          |
| Node.js          | 24.x            |
| 환경변수         | 없음            |

Root Directory는 `package.json`과 `vercel.json`이 있는 폴더로 지정합니다. 링크별 미리보기를 제공하는 서버 함수가 필요하므로 `dist/`만 정적 호스팅에 업로드하는 방식은 지원하지 않습니다.

## 개인정보와 공유

설문 답변과 개인화 성찰은 브라우저 메모리에만 보관하며, 새로고침하면 사라집니다. 로그인, 외부 분석 도구, 쿠키, 브라우저 저장소를 사용하지 않습니다.

공유를 선택하면 점수와 입력한 별명만 공개 URL에 포함됩니다. 링크를 받은 사람과 링크 미리보기 서비스는 이 정보를 볼 수 있습니다. 설문 답변이나 개인화 성찰은 공유하지 않습니다.

공유 점수는 URL에서 수정할 수 있는 오락용 정보이며, 인증된 결과나 순위를 의미하지 않습니다.
